# Histórico de versões

Esta página é a linha do tempo das atualizações do sistema. As versões aparecem da mais antiga para a mais recente.

## 1.0.0 — 30/09/2026

- Sistema web de vendas, estoque e fluxo de caixa para a confeitaria.
- Cadastro e edição de produtos, PDV, baixa automática de estoque e relatórios financeiros em PDF.
- Controle administrativo de lançamentos, fechamento diário e reset completo.

## 1.1.0 — 30/09/2026

- Adicionado botão de acessibilidade com alto contraste e navegação por teclado aprimorada.
- Ajustado o layout responsivo para uso com zoom do navegador.
- Adicionado reconhecimento de voz no PDV para incluir produtos pela fala.
